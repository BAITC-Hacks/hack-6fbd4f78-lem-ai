# AI Sana — демонстрационный MVP

Бизнес создаёт карточку задачи, проверяет полноту и публикует её в каталоге. Команды отправляют предложения, бизнес вручную выбирает одну команду.

## Запуск на любом компьютере

**Без установки программ:** скачайте и откройте двойным щелчком файл `demo.html`. В нём уже находятся интерфейс, стили и код. Интернет и компьютер автора не нужны. Можно также открыть `index.html`, сохранив рядом `app.js` и `styles.css`.

Для стабильного адреса и хранения данных запустите сервер из корневой папки проекта (нужен Python 3).

macOS / Linux:

```sh
python3 -m http.server 8000
```

Windows:

```powershell
py -m http.server 8000
```

Откройте http://localhost:8000. Абсолютных путей к компьютеру автора в проекте нет.

## Что исправлено

- Все рейтинги вычисляются одной функцией при загрузке, редактировании и сохранении; старые сохранённые оценки пересчитываются. Начальные значения: 100, 90, 90, 90, 90.
- Расшифровка всех семи показателей видна в конструкторе и раскрывается в каталоге.
- Контакт входит в редактируемую карточку и отображается в каталоге. Публикация требует названия, контакта и ручного подтверждения. Низкий рейтинг не запрещает публикацию.
- Ручной черновик сохраняется до запуска анализа; повторное сохранение не создаёт копий. Последняя сохранённая карточка восстанавливается после перезагрузки. Сохранение опубликованной карточки не снимает её с публикации.
- Поиск игнорирует регистр и пробелы по краям; ищет по названию, компании, отрасли, контексту и пользователям. Доступны фильтр готовности и сортировка по рейтингу / дате.
- Отклик проверяет команду, длину идеи и плана (по 20 символов), необязательную HTTP(S)-ссылку. Одна команда отправляет один отклик на задачу. Только в режиме бизнеса можно принять предложение; для задачи допускается одна принятая команда.
- Ссылки с исполняемыми схемами блокируются, пользовательский текст экранируется. Ошибки записи localStorage показываются пользователю без сообщения об успешном сохранении.

## Формула рейтинга

| Показатель | Максимум |
|---|---:|
| Контекст и потребность | 20 |
| Данные и материалы | 20 |
| Ожидаемый результат | 15 |
| Критерии успеха | 15 |
| Ограничения | 10 |
| Пользователи | 10 |
| Контакт и формат взаимодействия | 10 |

Показатель получает весь вес, если после удаления крайних пробелов содержит минимум 8 символов. Для последнего показателя оба поля должны содержать минимум 8 символов каждое. Иначе начисляется 0. Это проверка полноты, а не смысловая оценка качества. Уровни: 0–39 — черновик, 40–69 — рабочая, 70–89 — готовая, 90–100 — приоритетная.

## Локальный анализ и fallback

Внешняя модель не подключена. Локальный анализ использует введённые данные и задаёт до пяти вопросов по незаполненным показателям. Полная карточка не требует вопросов. Компания и контакт из исходного ввода переносятся в карточку; имеющиеся ручные значения сохраняются.

Ответ проходит `validateAnalysis`: проверяются JSON, массивы, поля вопросов и соответствие пропусков локальному расчёту. Некорректный ответ заменяется локальными вопросами без добавления фактов. Переключатель «Демо: некорректный ответ AI» позволяет проверить эту ветку из интерфейса. Контакт редактируется в карточке, ответ на вопрос о взаимодействии заполняет формат. Ответы после анализа нужно сохранить кнопкой.

Рекомендации команд и сравнение откликов также являются локальными эвристиками. Они не назначают исполнителя. Подзадачи создаются по шаблону из контекста родителя, журнал прогресса заполняется вручную. Если подключать настоящую модель, ключ должен находиться на сервере.

## Хранение и ограничения демо

Данные находятся в localStorage текущего браузера, ключ `ai-sana-mvp-v1`. Общего сервера и обмена между компьютерами нет. Переключатель ролей демонстрационный, не является авторизацией. Не используйте демо как защищённую многопользовательскую систему.

При открытии через file:// поведение localStorage зависит от браузера; для предсказуемого хранения используйте HTTP-запуск. При повреждённом или несовместимом JSON загружается тестовый набор. При запрете записи изменения остаются только в памяти до закрытия страницы. «Сбросить демо» удаляет сохранённые данные этого демо и возвращает тестовый набор.

## Проверка и сборка

При установленном Node.js:

```sh
node tests/app.test.cjs
node build-demo.cjs
```

Тесты выполняют код приложения с имитацией DOM и localStorage: рейтинг, ручное сохранение и восстановление, подтверждение публикации, поиск, fallback, ссылки, дубли откликов, единственный выбор команды и ошибки хранилища. Это логические регрессионные проверки, не визуальные браузерные тесты.

Сборка обновляет автономный `demo.html`. Можно разместить этот файл как `index.html` на статическом хостинге. Публичная интернет-ссылка в этой поставке не создана.
