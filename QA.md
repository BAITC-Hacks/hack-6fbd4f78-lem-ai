# Проверка итоговой версии AI Sana

Дата: 23 сентября 2026. Проверен проект из `Downloads/hack-6fbd4f78-lem-ai-main`.

## Исправлено

- Оба сервера отдают только четыре публичных файла. `.env`, файлы серверов, тесты и скрытые пути закрыты.
- Изменённый и очищенный контакт корректно считывается, сохраняется и восстанавливается. Устранена ошибка обращения к отсутствующему полю контакта.
- Ответы на уточняющие вопросы сразу переносятся в карточку и пересчитывают рейтинг.
- Бизнес может принять несколько команд на одну задачу.
- Добавлены подтверждённые этапы: 20 баллов за каждый из пяти этапов, максимум 100 на команду и задачу, без повторного начисления.
- Добавлен фильтр отрасли, совместимый с поиском и фильтром готовности.
- При генерации LLM старые поля очищаются, повторный запуск и сохранение блокируются. Поздний ответ закрытой карточки не заполняет другую задачу.
- Сохранённая подзадача показывает источник LLM API / локальный fallback и все шесть полей.
- Локальные проверки откликов больше не обозначены как ответы AI.
- Обновлены README, сценарий защиты, `.env.example` и сборка `demo.html`.

## Проверка в Chrome

В отдельной тестовой сессии на `http://localhost:8107/` пройдены:

1. Слабое описание → шесть вопросов. Получен финальный статус «Вопросы подготовлены LLM API».
2. Ответ на вопрос о данных → рейтинг 20 → 40. Результат сохранён после обновления страницы.
3. Полностью заполненная карточка → 100/100; публикация доступна после ручного подтверждения.
4. Изменение контакта → сохранение → обновление → новый контакт виден в опубликованной карточке.
5. Фильтр «Ритейл» показывает соответствующую задачу; поиск, отрасль и готовность работают совместно.
6. Два предложения от Qadam и Nomad Labs → ручное принятие обоих.
7. Завершение этапа без подтверждения блокируется; после подтверждения — 20 баллов.
8. Повторное подтверждение того же этапа — 0 новых баллов. После обновления сохранены оба принятых отклика и сумма 20.
9. В таблице команд отображаются заработанные баллы.
10. Другой отклик вручную отклонён; показан статус «Отклонено».
11. Подзадача получена с финальным статусом «Черновик подготовлен LLM API», сохранена и отображается с источником и входными данными.
12. Принудительный fallback формирует шесть вопросов без вызова модели.
13. Собранная `demo.html` открывается; фильтр отрасли работает. В доступном журнале консоли ошибок JavaScript не обнаружено.

## Запуск после обновления

Код серверов применяется только после перезапуска процесса. Во время проверки обновлённый Python-сервер работал на порту 8107; запрос `/.env` возвращал 403.

Старый процесс на порту 8000 был запущен до исправлений. Среда проверки не разрешила остановить его. В его терминале нажмите `Ctrl+C`, затем из папки проекта выполните `python3 server.py`. После этого используйте `http://localhost:8000/` и обновите страницу.

Ключ в локальном `.env` не изменялся. В архив для сдачи он не включается. Данные проекта по-прежнему хранятся в localStorage; общей базы и серверной авторизации нет.
