# Выступление на 5 минут

Перед выступлением откройте demo.html на компьютере для показа. В разделе «Демонстрация» нажмите «Сбросить демо». Используйте тестовые данные; сброс удаляет предыдущие изменения.

## 0:00–0:40 — проблема и решение

«Бизнес часто приносит идею без данных и критериев результата. Команде трудно оценить объём. AI Sana превращает описание в проверяемую карточку и показывает, какие сведения нужны для начала работы».

Откройте конструктор, загрузите слабое описание, нажмите «Проверить полноту и создать карточку». Покажите вопросы. Уточните: «В демо работает локальный анализ; внешняя модель не подключена».

## 0:40–2:00 — карточка и прозрачный рейтинг

Заполните поля:

| Поле | Текст для демонстрации |
|---|---|
| Название | Запись в клинику без очереди |
| Контакт | Алия · business@example.com |
| Контекст | Пациенты долго ждут в очереди; нужна удобная запись на свободное время. |
| Пользователи | Пациенты и регистраторы городской клиники. |
| Данные | Тестовое расписание пяти врачей и примеры записей. |
| Результат | Интерактивный прототип записи на свободное время. |
| Критерии | Пациент выбирает время и получает подтверждение за три шага. |
| Ограничения | Четыре часа, только тестовые данные, без медицинских интеграций. |
| Формат | Два созвона с заказчиком и обратная связь в чате. |

Покажите 100/100 и начисления по каждому показателю. «Рейтинг измеряет полноту сведений. Решение о публикации остаётся за человеком».

Сохраните карточку и обновите страницу: поля восстановятся. Отметьте подтверждение, опубликуйте, найдите задачу по слову «очереди». Раскройте поля и рейтинг в каталоге.

## 2:00–3:10 — предложение команды

Переключитесь в режим студента. У созданной задачи нажмите «Подать предложение», выберите Qadam.

Идея: «Сделаем мастер записи с выбором врача и свободного времени».

План: «За четыре часа: подготовим расписание, форму записи и экран подтверждения; проверим три шага с заказчиком».

Ссылку можно оставить пустой. Отправьте отклик. Покажите, что повторный отклик этой команды блокируется.

## 3:10–4:00 — решение бизнеса

Вернитесь в режим бизнеса, откройте «Отклики команд», покажите сравнение и вручную примите Qadam. Добавьте этап: «Подготовлена форма выбора врача; ожидаем проверку заказчика». Обновите страницу, покажите сохранённое решение.

«Рекомендация помогает сравнить предложения, но команда не назначается автоматически. На задачу выбирается один исполнитель».

## 4:00–4:40 — отказоустойчивость

В конструкторе загрузите новый слабый пример. Включите «Демо: некорректный ответ AI», запустите анализ. Покажите сообщение fallback и вопросы; исходные факты сохранены. Снимите переключатель.

## 4:40–5:00 — завершение

«Демо открывается одним HTML-файлом на любом компьютере. В MVP проверены карточка, рейтинг, публикация, отклик и ручное решение. Следующий этап — серверное хранение, авторизация и подключение модели через backend».

Если спросят о совместной работе: текущие данные локальны для браузера. Публичный статический сайт сам по себе не добавит общее хранилище.
